# 电气接口智能体（IPT）

电动飞机全机电气接口（EICD）场景智能体：以已治理的 EICD 数据库为基座，构建领域本体、知识图谱与内网可部署的智能体服务，提供电气链路追踪、变更影响分析、数据质量体检等能力。

- **接手开发**：读 [`CLAUDE.md`](CLAUDE.md)（用 Claude Code 打开本仓库会自动加载），任务全集在 [`docs/开发任务书-内网部署版智能体.md`](docs/开发任务书-内网部署版智能体.md)
- **数据从哪来**：`data/` 与 `graph/` 的数据文件不入库，获取方式见 [`data/README.md`](data/README.md)
- **项目里程碑**：8/25 内网可部署 v1（3 Skill）；9/25 十 Skill 全量发布
- **关键数字**：知识图谱 v0 — 210,640 节点 / 401,938 关系（权威出处 `graph/stats.md`）
