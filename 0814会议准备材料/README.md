# 0814 会议准备材料

会议用途：汇报进展与卡点、更新总表、向同事展示交付物。全部 HTML 为自包含单文件，**双击即可在浏览器打开**，无需联网。

## 使用顺序

| 文件 | 用途 | 什么时候用 |
|---|---|---|
| `01-进展与卡点汇报.html` | 进展硬数字 + 三个卡点（各带兜底与请求协调事项）+ 下两周路线 | 会上汇报主材料 |
| `02-交付物展示.html` | 交付物清单与**存储路径**、三个 30 秒现场演示指引、本体地图、真实链路走查 | 展示交付物时投屏 |
| `03-总表更新内容.html` | 总表逐列填报内容对照（点击文本块即全选，便于复制） | 会后更新总表 |
| `附件1-…-V1 的副本.xlsx` | 已填好的统计表（序号 1 行，34 个单元格） | 可直接交表 |
| `04-项目进度看板.html` | 11 周计划全景看板（可逐周展开）+ 图谱构成图 + 汇报口径 | 备用：被追问细节时打开 |
| `05-本体与图谱浏览器.html` | 本体三层 22 类 / 32 种关系完整地图、真实节点 JSON 样例、链路走查 | 备用：被追问"图谱里到底存了什么"时打开 |
